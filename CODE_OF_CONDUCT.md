# Code of Conduct

Anvil is a source-available project for people building computer-vision datasets,
models, and tooling. We want the project to be useful, welcoming, and practical.

## Expected Behavior

- Be respectful and assume good intent.
- Keep discussions focused on the project, the code, and user outcomes.
- Give constructive feedback with enough context that someone can act on it.
- Be patient with new contributors and first-time source-code contributors.
- Credit ideas, bug reports, designs, and prior work when you build on them.

## Unacceptable Behavior

- Harassment, threats, hate speech, or personal attacks.
- Sexualized language or imagery in project spaces.
- Doxxing, publishing private information, or pressuring people to reveal it.
- Repeated off-topic comments after maintainers ask you to stop.
- Intentionally wasting maintainer time with bad-faith reports or spam.

## Reporting

If you see behavior that violates this code, contact the maintainers privately:

- GitHub: open a private security advisory if the issue includes sensitive info.
- Email: `maintainers@anvil-cv.dev`

Reports should include links, screenshots, or timestamps when possible. The
maintainers will review reports, take action proportionate to the situation, and
protect reporter privacy as much as practical.

## Enforcement

Maintainers may remove comments, close issues, block users, or limit access to
project spaces. Serious or repeated violations may lead to a permanent ban.

This code applies to GitHub issues, pull requests, discussions, project chats,
events, and any official Anvil community spaces.
